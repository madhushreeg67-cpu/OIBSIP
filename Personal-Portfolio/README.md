# Personal Portfolio · Madhu S

A modern, responsive digital résumé and personal portfolio website showcasing engineering projects, technical skills, education, certifications, and athletic achievements.

## Tech Stack
- **Structure:** HTML5 Semantic Elements
- **Styling:** Vanilla CSS3 (Custom Design System, Midnight Dark Palette, Glassmorphism, Micro-animations)
- **Scripting:** Vanilla JavaScript (ES6+ for interactive menu, scroll spy, form handling)
- **Typography:** Google Fonts (Outfit, Plus Jakarta Sans, JetBrains Mono)
- **Icons:** SVG Vector Icons

## Features
- **Hero & Profile Section:** Professional avatar headshot, status badge, role details, and instant contact buttons.
- **About Me & Education:** Career objective, CGPA highlights, and chronological educational timeline.
- **Skills Matrix:** Categorized technical skills spanning programming, hardware/embedded systems, DSP/tools, and professional leadership.
- **Featured Projects:**
  1. *Intelligent Solar Charge Controller with MPPT & Cloud Monitoring* (ESP32, IoT, Solar PV)
  2. *Automated Pesticide Sprayer & Harvesting System* (Srishti Innovation Exchange 2025)
  3. *FarmCare Dairy Health & Management Portal* (Oasis Infobyte Task 1)
- **Certifications & Sports Achievements:** Machine Learning credentials and VTU / Yuva Dasara athletic championship honors.
- **Interactive Contact Section:** Direct email, phone, location, LinkedIn/GitHub links, and validated message form.
- **Responsive Design:** Optimized for mobile phones, tablets, and desktop displays.

## Running the Website Locally

Double-click `index.html` or open in terminal:
```powershell
Start-Process .\index.html
```
Or serve with:
```powershell
npx -y serve .
```
