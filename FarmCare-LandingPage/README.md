# FarmCare 🐄 — Better Care. Healthier Cows.

**FarmCare** is a modern, compassionate dairy farm landing page designed to empower dairy farmers with scientific animal care, nutrition schedules, comfortable cow & buffalo housing, hygiene standards, and preventive veterinary guidance.

## Project Structure

```
MooFarm-LandingPage/
├── index.html          # Main HTML structure with care programs, daily routines, & advisory
├── style.css           # Natural rich forest green & pasture cream responsive styling
├── README.md           # Project documentation and details
└── images/             # Real dairy cow care photography
    ├── hero-cow.jpg    # Mother cow and calf in lush green pasture
    ├── feeding-care.jpg# Feeding & balanced green fodder nutrition
    ├── housing-care.jpg# Clean, well-ventilated cow & buffalo shelter
    ├── health-care.jpg # Veterinary checkups & preventive health
    ├── calf-care.jpg   # Compassionate calf neonatal feeding
    └── milking-care.jpg# Hygienic milking parlor & udder care
```

## Running the Website Locally

You can run the project using:

```powershell
npx -y serve MooFarm-LandingPage
```
Or open directly:
```powershell
Start-Process .\MooFarm-LandingPage\index.html
```
