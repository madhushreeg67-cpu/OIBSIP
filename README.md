# OIBSIP

Oasis Infobyte Web Development &amp; Designing Internship

This repository contains the projects developed during the **Web Development and Designing Internship** at **Oasis Infobyte**.

---

## 📌 Projects

### 🐄 Task 1: FarmCare Landing Page
A modern, responsive landing page for **FarmCare — Better Care. Healthier Cows.**, offering practical guidance for dairy farmers on animal health, scientific nutrition, housing standards, and daily care routines.

- **Directory:** [`FarmCare-LandingPage/`](./FarmCare-LandingPage)
- **Technologies Used:** HTML5, CSS3, Google Fonts (Plus Jakarta Sans &amp; Outfit), Responsive Design
- **Key Features:**
  - Responsive Navigation &amp; Hero Section with high-resolution cow photography
  - 6 Comprehensive Care Pillars (Nutrition, Housing, Vet Care, Calf Growth, Milking Hygiene, Seasonal Protection)
  - 3-Step Daily Routine Checklist (Morning, Midday, Evening)
  - Farmer Testimonial &amp; Value Highlights
  - Free Farm Advisory Consultation Form

### How to Run Locally

Navigate into any task folder:
```bash
# Task 1
cd FarmCare-LandingPage
Start-Process index.html

# Task 2
cd Personal-Portfolio
Start-Process index.html
```
Or serve using `npx serve`:
```bash
npx -y serve .
```
